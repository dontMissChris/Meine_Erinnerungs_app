# Erinnerungs-App ???

Eine WPF-Desktop-Anwendung für Termin-Verwaltung mit Live-Countdown und visuellen Alarmen.

![Screenshot der App](screenshot.png)

## Features

- ? Termine mit Datum und Uhrzeit anlegen
- ?? Live-Countdown bis zum Termin
- ?? Farbwechsel basierend auf verbleibender Zeit (Gold ? Orange ? Rot)
- ?? Popup-Alarm bei Ablauf
- ?? Fortschrittsbalken für jeden Termin
- ? Animierte Benutzeroberfläche mit Lösch-Animation

## Technologien

- **C#** / .NET Framework 4.8
- **WPF** (Windows Presentation Foundation)
- **XAML** für UI-Design
- **DispatcherTimer** für Live-Updates
- **Data Binding** mit `INotifyPropertyChanged`
