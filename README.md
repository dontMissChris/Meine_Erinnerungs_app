# 📅 Meine Erinnerungs-App

Eine moderne Windows-Desktop-Anwendung zur Verwaltung von Erinnerungen mit intuitiver Benutzeroberfläche.

## ✨ Features

- **Einfache Eingabe**: Übersichtliche Eingabefelder für Grund, Datum und Uhrzeit der Erinnerung
- **Benutzerfreundliches Design**: Moderne Oberfläche mit Farbverlauf-Hintergrund
- **⏱️ Erinnerungsverwaltung**: Erstellen und Verwalten von zeitbasierten Erinnerungen
- **🎨 Visuelles Feedback**: Klare visuelle Rückmeldungen durch Platzhaltertexte und Fokussteuerung

## 🔧 Technologie-Stack

- **Sprache**: C# (.NET Framework 4.8)
- **UI-Framework**: Windows Presentation Foundation (WPF)
- **IDE**: Visual Studio
- **Architektur**: XAML-basierte Benutzeroberfläche mit Code-Behind-Pattern

## 📊 Verwendung

1. **Anwendung starten**: Öffnen Sie die kompilierte .exe-Datei
2. **Erinnerung erstellen**:
   - Geben Sie den Grund der Erinnerung ein
   - Tragen Sie das gewünschte Datum ein
   - Fügen Sie die Uhrzeit hinzu
   - Klicken Sie auf "GO!" zum Aktivieren
3. **Erinnerung löschen**: Nutzen Sie den "Löschen"-Button zum Entfernen

## 🚀 Installation & Build

### Voraussetzungen
- Visual Studio 2017 oder höher
- .NET Framework 4.8 SDK

### Build-Anweisungen
1. Öffnen Sie die Solution-Datei `Meine_Erinnerungs_app.sln` in Visual Studio
2. Wählen Sie die gewünschte Konfiguration (Debug/Release)
3. Drücken Sie F5 oder wählen Sie "Build" > "Build Solution"
